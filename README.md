# csv-row-check

## 概要

CSVファイルを読み込み、先頭行の項目名を基準とし２行目以降で空欄のセルと各行の列数とヘッダーの項目数を比べて一致しているかを調べ、
問題があれば行番号・列番号・項目名・判定を表示し、問題箇所を知ることができます。

## インストール

ターミナルで次のコマンドを実行します。

```bash
$ git clone https://github.com/s25c1073pa-cyber/csv-row-check.git
$ cd csv-row-check
$ chmod +x csv-row-check
```

## 使い方

確認したいCSVファイルを読み込み次の様に実行します。
例が読み込んでいるファイルは「data.csv」です。

```bash
$ cat data.csv | ./csv-row-check
```

## 入出力

入力は1行目に項目名があるCSVファイルです。
2行目以降の空欄や、項目数の不足・余分を確認できます。

入力例↓

```csv
名前,年齢,出身地
太郎,20,東京
花子,,大阪
次郎,21
三郎,18,札幌,備考
```

出力は「行番号、列番号、項目名、判定」の順です。
行番号はヘッダーを１行目として数えます。
問題がなければ何も出力されません。
余分な列には対応する項目名がないため、項目名は空欄になっています。
列数が足りない場合は末尾の列が不足として扱われます。

出力例↓

```text
3,2,年齢,不足
4,3,出身地,不足
5,4,,余分
```

## 動作環境とテスト

Python 3.12で動作します。テストは次のコマンドで実行できます。

```bash
$ bash test.bash
```
